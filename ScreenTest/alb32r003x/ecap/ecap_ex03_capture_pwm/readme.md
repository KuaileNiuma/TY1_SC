## ecap_ex03_capture_pwm

### 1 概述
本例程展示了ECAP（增强型捕获模块）的捕获模式功能。通过配置ECAP模块为捕获模式，捕获PWM波形的时间戳，并根据捕获结果验证PWM周期，同时动态调整PWM的频率。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程配置ECAP1为捕获模式：
- 设置事件极性：事件1为下降沿，事件2为上升沿，事件3为下降沿，事件4为上升沿
- 配置计数器在每个事件时重置
- 选择ECAP输入为INPUTXBAR7
- 启用事件4的中断

配置EPWM1：
- 工作在递增计数模式
- 周期匹配时切换输出
- 初始周期为PWM1_TIMER_MIN

在中断服务程序中：
- 读取事件2、3、4的捕获时间戳
- 验证捕获值与预期周期的一致性
- 根据当前周期值调整EPWM的频率方向：当周期达到最大值时减少频率，当周期达到最小值时增加频率
- 根据方向调整周期值，实现频率的动态变化

### 4 运行现象
可以通过示波器或逻辑分析仪抓取波形观察
测试现象：
```
1. ECAP1成功捕获PWM波形的时间戳
2. 捕获值与预期周期一致
3. EPWM1的频率在PWM1_TIMER_MIN和PWM1_TIMER_MAX之间动态变化
4. 中断计数器和成功捕获计数器递增
```
