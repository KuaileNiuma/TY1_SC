## zhanlu_ex03_test

### 1 概述
本例程展示了Viterbi编解码功能的测试。通过执行viterbi_test()函数，测试Viterbi编码器和解码器的性能，验证ZHANLU_NICE指令集在信号处理方面的能力。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程执行以下操作：
- 初始化系统和板卡
- 调用viterbi_test()函数执行Viterbi编解码测试
- 打印测试完成信息
- 进入无限循环

### 4 运行现象
测试现象：
```
1. 执行Viterbi编解码测试
2. 测试完成后打印"test end"
3. 程序进入无限循环
```
