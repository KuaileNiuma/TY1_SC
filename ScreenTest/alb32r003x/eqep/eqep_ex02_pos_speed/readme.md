## eqep_ex02_pos_speed

### 1 概述
本例程展示了通过逻辑分析仪检测EPWM能够产生5 kHz的正交信号方波，通过Index信号复位计数值，从而进行15组信号频率的测量，捕获测量出的频率均在300±20 rpm（4*5 kHz = 300 rpm）范围内，且记录的计数器值逐渐增加（不超过4000）

### 2 准备
ALB32R0039_EVM开发板
接线如下：
EQEP1:GPIO0  - GPIO10 
      GPIO1  - GPIO11 
      GPIO30 - GPIO23 
EQEP2:GPIO0  - GPIO14 
      GPIO1  - GPIO15 
      GPIO30 - GPIO26 

### 3 运行步骤
1.配置ePWM模块产生两路正交PWM信号（默认5 kHz，相位差90°），模拟编码器的A相和B相信号 
2.配置GPIO产生周期性索引脉冲（Index信号），模拟编码器的每转参考信号 
3.配置eQEP为正交计数模式，设置位置计数器的最大计数值和重置条件 
4.执行单位定时器法高速测量：通过统计10ms内的位置计数变化计算转速（RPM） 
5.执行捕获单元法低速测量：通过测量固定边沿数的时间间隔计算低转速 
6. 在ePWM中断服务程序中计数中断次数，每1000次中断（200ms）产生一个索引脉冲 

### 4 运行现象
串口会将测试结果直接打印出来，参考如下
```
    eqep_test ok!.
    
```
