## eqep_ex05_speed_dir_motor

### 1 概述
EPWM产生的方波频率为5 kHz，且eQEP捕获测量出的信号频率为20 kHz

### 2 准备
ALB32R0039_EVM开发板
接线如下：
EQEP1:GPIO0  - GPIO10 
      GPIO1  - GPIO11 
      GPIO30 - GPIO23 
EQEP2:GPIO0  - GPIO14 
      GPIO1  - GPIO15 
      GPIO30 - GPIO26 

### 3 运行步骤
1.配置ePWM1A和ePWM1B模块产生5kHz的相位差为90°的正交PWM信号，模拟电机编码器输出 
2.通过条件编译支持真实电机连接或模拟信号测试两种模式 
3.配置eQEP模块为正交计数模式，用于处理两相正交信号，配置eQEP单位定时器超时中断，触发速度计算 
4.设置单位定时器周期为10ms（100Hz），用于周期性速度测量
5. 在中断服务程序中读取eQEP的方向状态寄存器，根据旋转方向（顺时针或逆时针）调整位置计数差值计算逻辑，根据旋转方向采用不同的位置计数差值计算算法 

### 4 运行现象
通过eQEP捕获测量出的频率在20000±100 Hz范围内
