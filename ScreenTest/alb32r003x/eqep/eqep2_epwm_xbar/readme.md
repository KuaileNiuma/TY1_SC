## eqep2_epwm_xbar

### 1 概述
本例程展示了EPWM产生的方波频率为5 kHz，且eQEP捕获测量出的信号频率为4949 Hz 。

### 2 准备
ALB32R0039_EVM开发板
接线如下：
GPIO30-GPIO0

### 3 运行步骤
1.配置ePWM1A模块产生5kHz的PWM测试信号 
2.配置输入交叉开关（Input XBAR）将GPIO0设置为输入信号源 
3.配置ePWM XBAR模块，将TRIP4与输入交叉开关的输出1相连接 
4.配置eQEP的A相信号源为PWMXBAR1输出，建立内部信号通路 
5.设置eQEP模块的信号源选择，将eQEPA配置为使用PWMXBAR1作为输入源 
6.配置eQEPB和索引信号使用设备引脚作为输入源 
7.配置eQEP模块的单位定时器为100Hz采样频率，用于高频信号测量 ，配置捕获单元的参数设置，用于低频信号测量 

### 4 运行现象
通过eQEP捕获测量出的频率在5000±60 Hz范围内
