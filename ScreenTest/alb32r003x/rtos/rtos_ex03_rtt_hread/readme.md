## rtos_ex03_rtt_hread

### 1 概述
本例程展示了RT-Thread实时操作系统的基本功能。通过创建多个静态线程，演示了线程的创建、启动和调度执行过程，并通过串口输出线程运行状态。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程执行以下操作：
- 初始化系统和板卡
- 调用create_thread_demo()函数创建5个静态线程
- 启动所有创建的线程
- 主线程每500ms执行一次，打印计数信息
- 每个创建的线程每250ms执行一次，打印线程编号和计数信息

### 4 运行现象
测试现象：
```
1. 5个线程被创建并启动
2. 主线程每500ms输出一次"Main thread count: X"
3. 5个线程每250ms输出一次"thread X count: X"
4. 在模拟环境下，主线程执行3次后会退出
```
