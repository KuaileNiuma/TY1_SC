## rtos_ex04_threadx

### 1 概述
本例程展示了ThreadX实时操作系统的基本功能。通过创建8个不同优先级的线程，演示了线程的调度和执行过程，并使用消息队列、信号量、互斥锁、事件标志组、字节池和块池等ThreadX核心功能。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程执行以下操作：
- 初始化系统和板卡
- 进入ThreadX内核
- 在tx_application_define函数中创建字节池
- 创建8个线程，每个线程具有不同的优先级和功能
- 创建消息队列、信号量、互斥锁、事件标志组和块池
- 线程0：每10个tick执行一次，设置事件标志唤醒线程5
- 线程1：向队列发送消息
- 线程2：从队列接收消息
- 线程3和4：竞争信号量
- 线程5：等待事件标志
- 线程6和7：竞争互斥锁

### 4 运行现象
测试现象：
```
1. 8个线程被创建并自动启动
2. 线程6和7的运行信息通过串口输出（因为DEBUG_THREAD_6_7被定义）
3. 线程6和7每2个tick竞争一次互斥锁
4. 在模拟环境下，线程7执行3次后会退出
```
