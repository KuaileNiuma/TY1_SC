## aes_ex01_encode

### 1 概述
本例程展示了AES（高级加密标准）的加密功能。通过配置AES为128位加密模式，对输入数据进行加密处理，并输出加密结果。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤
1. 初始化AES密钥：设置128位密钥（4个32位字）
2. 初始化输入数据：准备16字节（4个32位字）的明文数据
3. 启用AES外设时钟
4. 配置AES为128位加密模式，设置密钥
5. 写入输入数据到AES模块
6. 启动AES加密过程
7. 等待加密完成
8. 读取加密结果并打印

### 4 运行现象

```
AES EX01 ENCODE.
0x16A6B6AB
0x1842A99B
0x55CF8D92
0x635F8017
```
