## wwdt_ex01_reset

### 1 概述
本例程展示了窗口看门狗定时器系统复位模式功能

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤
软件执行窗口看门狗定时器系统复位模式测试。
具体流程为：初始化窗口看门狗定时器→配置窗口看门狗参数→使能窗口看门狗复位→等待系统复位。

### 4 运行现象
程序启动窗口看门狗定时器后，读取 CR 寄存器 T[6:0]（当前递减计数值）两次，若计数值递减则证明看门狗计时器工作正常，打印 `WWDT system reset test OK` 并返回 SC_PASS（随后系统会自动复位）。
若计数器未递减，打印 `WWDT system reset test FAIL` 并返回 SC_FAIL。
