## sdfm_ex04_type1_filter_fifo_cpuread

### 1 概述
本例程展示了SDFM通道一能正常输出滤波值并触发FIFO数据就绪中断

### 2 准备
1.ALB32R0039_EVM开发板
2. 信号发生器提供20MHz时钟以及312.5mV的直流差分电压
3. AMC1305M025芯片数据输出引脚连接至SD_Dx(x = 1-4)
4. 20MHz时钟同时连接至AMC1305M025芯片时钟输入引脚以及SD_Cx(x = 1-4)

### 3 运行步骤
1. 设置所有滤波器通道一的调制器时钟与数据速率相等（MODE0 模式）
2. 配置比较器使用 Sinc3 滤波器，过采样率 OSR=32，高阈值 0x7FFF，低阈值 0x0000
3. 配置数据滤波器使用 Sinc3 滤波器，OSR=128，输出为 16 位格式，右移7位以适配 25 位数据
4. 启用主滤波器使能位（MFE），实现滤波器同步
5. 开启通道一的FIFO，设置FIFO阈值为16
6. 使能通道一的FIFO数据就绪中断以及FIFO溢出中断，使能通道一的调制器错误中断

### 4 运行现象
1.通道一的缓冲区都能正常采样到滤波值，能正常触发FIFO数据就绪中断且不出现调制器错误
2.查看串口打印信息
