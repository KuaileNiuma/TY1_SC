## cmpss_ex02_digital_filter

### 1 概述
本例程展示了CMPSS（比较器子系统）的数字滤波器功能。通过配置CMPSS1的高比较器和数字滤波器，实现对输入信号的滤波处理，消除噪声干扰，提高比较器的可靠性。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程使能比较器CMPSS1_COMPH，比较器CMPSS1_COMPH中外部电压CMPIN1P用于提供正输入，内部DAC用于提供负输入，并且内部DAC配置为使用VDDA作为参考，设置DAC值为1551

配置数字滤波器：
- 高比较器：时钟预分频为6，采样窗口大小为16，阈值为8
- 低比较器：时钟预分频为0，采样窗口大小为1，阈值为1

配置OUTPUTXBAR，将CMPSS1的CTRIPOUTH信号输出到OUTPUTXBAR3（GPIO14）

当接入外部电压到CMPIN1P时，比较器会对输入信号进行滤波处理，然后将结果输出到GPIO14

### 4 运行现象
可以通过示波器或逻辑分析仪抓取波形观察
测试现象：
```
1. 当CMPIN1P输入电压高于DAC设置的参考电压时，GPIO14输出高电平
2. 当CMPIN1P输入电压低于DAC设置的参考电压时，GPIO14输出低电平
3. 数字滤波器可以有效消除输入信号中的噪声，使输出信号更加稳定
```
