## sdfm_ex02_filter_sync_dmaread

### 1 概述
本例程展示了SDFM的四个通道均能通过DMA通道正常搬运滤波值

### 2 准备
1.ALB32R0039_EVM开发板
2. 信号发生器提供20MHz时钟以及312.5mV的直流差分电压
3. AMC1305M025芯片数据输出引脚连接至SD_Dx(x = 1-4)
4. 20MHz时钟同时连接至AMC1305M025芯片时钟输入引脚以及SD_Cx(x = 1-4)

### 3 运行步骤
1. 配置SDFM1模块的输入控制单元为MODE0模式，设置调制器时钟速率等于调制器数据速率
2. 所有4个滤波器通道配置比较器单元，选择Sinc3滤波器类型，设置比较器过采样率（OSR）为32，配置比较器的高阈值（HLT）为0x7FFF，低阈值（LLT）为0x0000
3. 配置所有4个数据滤波器单元，选择Sinc3滤波器类型用于主数据处理，设置数据滤波器的过采样率（OSR）为256，配置滤波器输出为16位格式，通过右移10位操作将25位内部数据转换为16位输出
4. 使能所有滤波器通道，使能主滤波器（Master Filter）位，实现所有4个滤波器通道的同步操作
5. 配置DMA通道传输以及中断，CH0-3分别别对应通道1-4，将四个通道分别采样进不同的缓冲区

### 4 运行现象
每个通道的缓冲区都能正常采样到滤波值，且不出现调制器错误
