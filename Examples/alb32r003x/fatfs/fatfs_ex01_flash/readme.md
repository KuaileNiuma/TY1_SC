## fatfs_ex01_flash

### 1 概述
本例程展示了使用FATFS文件管理功能

### 2 准备
ALB32R0039_EVM开发板
准备一块支持SPI协议的FLASH并按以下进行接线（电源线省略）
GPIO0 ->	CS
GPIO3 ->	CLK
GPIO1 ->	SOMI
GPIO2 ->	SIMO

### 3 运行步骤
软件执行SPI1和FLASH通信，对FLASH进行写入文件系统进行文件管理操作
具体流程为：卸载文件系统→挂载文件系统→检测到无文件系统则格式化→重新挂载→创建测试文件并写入数据→读取测试文件并验证→创建更多文件→获取文件信息→列出根目录文件

### 4 运行现象
串口会将测试结果直接打印出来。
