## eqep_ex01_freq_cal

### 1 概述
本例程展示了EPWM能够产生5kHz的方波，且通过eQEP捕获测量出的频率在5000±50 Hz范围内。

### 2 准备
ALB32R0039_EVM开发板
接线如下：
EQEP1:GPIO0  - GPIO10 
      GPIO1  - GPIO11 
      GPIO30 - GPIO23 
EQEP2:GPIO0  - GPIO14 
      GPIO1  - GPIO15 
      GPIO30 - GPIO26 

### 3 运行步骤
1.配置ePWM模块产生一个已知频率的PWM信号（5 kHz），作为eQEP模块的输入测试信号 
2.配置eQEP模块为单位定时器模式和捕获单元模式双测量方式 
3.设置单位定时器为100Hz采样频率，用于高频信号测量 
4.配置捕获单元的时钟预分频和边沿检测参数，用于低频信号测量 
5.在ePWM中断服务程序中调用频率计算函数，实现周期性测量 
6.执行单位定时器法频率测量：通过统计10ms内的脉冲计数变化计算高频信号频率 
7. 执行捕获单元法频率测量：通过测量固定边沿数的时间间隔计算低频信号频率 

### 4 运行现象
串口会将测试结果直接打印出来，参考如下
```
    FLASH EX01 Operation.
    FLASH EX01 Operation success.
```
