## clb_ex12_aoc

### 1 概述
本例程展示了CLB对输入信号进行逻辑操作。
先经过LUT4进行out=i0&i1逻辑操作，之后作为OUTLUT3模块i0的输入进行out=i0逻辑操作， 再输入到AOC模块，在STAGE1进行取反操作，在STAGE2进行AND操作另一个门控信号选择为 软件门控通过GP寄存器来控制。 

### 2 准备
ALB32R0039_EVM开发板
使用示波器连接GPIO2。

### 3 运行步骤
板级初始化 -> 配置CLB逻辑块为AND门 —> 使能CLB逻辑块。
