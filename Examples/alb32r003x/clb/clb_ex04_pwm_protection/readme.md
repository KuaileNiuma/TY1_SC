## clb\_ex04\_pwm\_protection

### 1 概述

本例程展示了CLB对 PWM 输出做硬件级保护，强制互补 PWM 始终满足最小死区时的功能。

### 2 准备

ALB32R0039\_EVM开发板
示波器连接GPIO0和GPIO1

### 3 运行步骤

具体流程为：
1.板级初始化 -> 初始化CLB -> 初始化EWPM。
2.在Expressions窗口添加变量mode,配置mode变量为0/1。
3.使用示波器捕获输出波形。

### 4 运行现象

在变量窗口使用mode变量来控制是否启用CLB功能，当mode=1时，PWM存在死区，当mode = 0时PWM输出无死区。
