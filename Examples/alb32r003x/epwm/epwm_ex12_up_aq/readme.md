## epwm_ex12_up_aq

### 1 概述
本例程展示了使用epwm的功能。

### 2 准备
ALB32R0039_EVM开发板
EPWM1A -> GPIO0
EPWM1B -> GPIO1
EPWM2A -> GPIO2
EPWM2B -> GPIO3
EPWM3A -> GPIO4
EPWM3B -> GPIO5

### 3 运行步骤
1.开启EPWM1/2/3,up计数模式下EPWM占空比的变化：每计数到3个周期，修改占空比

### 4 运行现象
1.EPWM1A/B输出波形的占空比在50/2000到1950/2000间变化，从x小到大再从大到小，A/B输出波形的占空比始终相同 2.EPWM4在输出一段事件波形后，通过软件强制持续拉低
2.EPWM2: A输出波形的占空比在50/2000到1950/2000间变化，从小到大再从大到小；B输出波形的占空比在50/2000到1950/2000间变化，从大到小再从小到大；占空比始终互补，相加为1
3.EPWM3: A输出波形的占空比在1900/2000到100/4000间变化，从大到小再从小到大；B输出波形不变，占空比始终为0.5
