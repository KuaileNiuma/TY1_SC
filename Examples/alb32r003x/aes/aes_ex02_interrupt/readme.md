## aes_ex02_interrupt

### 1 概述
本例程展示了AES（高级加密标准）的中断功能。通过配置AES为128位加密模式，对输入数据进行加密处理，并在加密完成时触发中断，实现异步处理。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤
1. 初始化AES密钥：设置128位密钥（4个32位字）
2. 初始化输入数据：准备16字节（4个32位字）的明文数据
3. 启用AES外设时钟
4. 注册AES中断处理函数
5. 设置AES中断优先级
6. 启用AES中断
7. 配置AES为128位加密模式，设置密钥
8. 写入输入数据到AES模块
9. 启动AES加密过程
10. 当加密完成时，触发中断，在中断服务程序中清除完成标志并打印中断信息
11. 读取加密结果并打印

### 4 运行现象

```
AES EX02 INTERRUPT.
aes interrupt
0x16A6B6AB
0x1842A99B
0x55CF8D92
0x635F8017
```
