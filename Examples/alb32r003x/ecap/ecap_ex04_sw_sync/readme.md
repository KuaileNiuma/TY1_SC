## ecap_ex04_sw_sync

### 1 概述
本例程展示了ECAP（增强型捕获模块）的软件同步功能。通过配置多个ECAP模块为捕获模式，并使用软件同步机制确保多个ECAP模块之间的同步，同时动态调整PWM的频率。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程配置三个ECAP模块：
- ECAP1：配置为捕获模式，设置事件极性，启用计数器加载，同步输出为同步输入
- ECAP2：配置为捕获模式，设置事件极性，启用计数器加载，禁用同步输出
- ECAP3：配置为捕获模式，设置事件极性，启用计数器加载，禁用同步输出，启用事件4的中断

配置EPWM1：
- 工作在递增计数模式
- 周期匹配时切换输出
- 初始周期为PWM1_TIMER_MIN

在中断服务程序中：
- 停止EPWM计数器
- 读取三个ECAP模块的所有事件时间戳
- 验证三个ECAP模块之间的同步性
- 根据当前周期值调整EPWM的频率方向：当周期达到最大值时减少频率，当周期达到最小值时增加频率
- 根据方向调整周期值，实现频率的动态变化
- 重新启动ECAP模块和EPWM计数器

### 4 运行现象
可以通过示波器或逻辑分析仪抓取波形观察
测试现象：
```
1. 三个ECAP模块成功捕获PWM波形的时间戳
2. 三个ECAP模块之间的捕获值保持同步
3. EPWM1的频率在PWM1_TIMER_MIN和PWM1_TIMER_MAX之间动态变化
4. 中断计数器和成功捕获计数器递增
```
