## ecap_ex01_apwm

### 1 概述
本例程展示了ECAP（增强型捕获模块）的APWM（模拟PWM）模式功能。通过配置ECAP模块为APWM模式，生成PWM波形，并通过OUTPUTXBAR输出到GPIO5引脚，同时动态调整PWM的频率。

### 2 准备
ALB32R0039_EVM开发板

### 3 运行步骤

该例程配置ECAP0为APWM模式，设置初始周期为4000000，初始比较值为1000000（25%占空比）

配置OUTPUTXBAR，将ECAP1的输出信号路由到OUTPUTXBAR3（GPIO5）

在主循环中：
- 设置占空比为50%
- 读取当前周期值
- 根据当前周期值调整频率方向：当周期达到最大值时增加频率，当周期达到最小值时减少频率
- 根据方向调整周期值，实现频率的动态变化

### 4 运行现象
可以通过示波器或逻辑分析仪抓取波形观察
测试现象：
```
1. GPIO5输出PWM波形
2. PWM频率在2.5Hz到5Hz之间动态变化
3. 占空比保持在50%
```
